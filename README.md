# ShopVerse
A microservice based ecommerce app using different tech stacks.

## Tech stack
- Python/FastAPI
- Java/SpringBoot
- Kafka
- Postgres
- Redis
- Angular
- Docker
- Kubernetes

## Repository layout
- deploy - Docker compose and Kubernetes
- docs - ADRs and diagrams
- frontend - Angular app
- libs - Contains shared code and event schemas
- observability - Contains grafana and prometheus configuration
- services - Contains backend services in python and java
